## 5. 已实现的数据预处理流程

代码位置：`recognition/UNet3D_s4984160/dataset.py`。

1. **`get_data_pairs()`：** 根据文件名前缀匹配 MRI 和 Mask 路径，并提取患者 ID。
2. **`split_by_patient()`：** 对不同患者 ID 进行可复现的随机打乱，按照 26/6/6 名患者划分 Train / Validation / Test，再分配每位患者的全部扫描。
3. **`HipMRIDataset.__getitem__()`：** 读取一对 MRI–Mask；检查 Shape 和 Affine；转成数值数组；仅对 MRI 的非零体素做 Z-score 归一化；将 NIfTI 数组轴 `(X,Y,Z)` 重新排列为 `(Z,X,Y)`；MRI 使用三线性插值、Mask 使用最近邻插值统一尺寸；最后返回 PyTorch Tensor。

**单样本成功测试后得到的输出形状：**

- MRI：`torch.Size([1, 64, 128, 128])`，对应（通道、深度、高度、宽度）。
- Mask：`torch.Size([64, 128, 128])`。
- 该测试样本输出的 Mask 标签：`tensor([0, 1, 2, 3, 4, 5])`。

成功运行 `python dataset.py` 时，程序实际只加载了**训练集中的一个样本**，并没有逐一加载全部 211 份扫描。
