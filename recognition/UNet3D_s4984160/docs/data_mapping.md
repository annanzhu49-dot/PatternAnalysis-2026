## 2. 切片方向、索引和翻转

全体 211 份三维文件头的数组轴方向均为 L/P/S。通过实际像素和标签匹配，以下规则在核对样本上精确成立：

```python
# i = 0..59；以下是原始 NIfTI 数组，尚未经过 dataset.py 转轴/降采样
slice_2d = volume_3d[::-1, 98 + i, :]
mask_2d  = mask_3d[::-1, 98 + i, :]
```

- 切自原始三维数组 axis=1，即第二个轴，索引 98..157（从 0 开始）。结合三维 L/P/S 方向，这是冠状面切片，随编号增加沿后方方向推进。
- 二维数组第一个轴相对原始三维平面进行了翻转，不能漏掉这个翻转。
- `slice_0` 对应三维第 98 层，`slice_30` 对应第 128 层，`slice_59` 对应第 157 层。
- 这些是中间 60 层，不是整个 256 层轴的完整覆盖。
- 回填预测的对应关系为 `volume_prediction[:, 98+i, :] = prediction_2d[::-1, :]`；未覆盖区域必须明确标记，不能当作模型已预测的背景。

## 3. 尺寸与空间信息

三维文件头已全部检查：210 份为 (256,256,128)，唯一例外是 K019_Week1_LFOV.nii.gz，为 (256,256,144)。对应抽查二维切片分别为 (256,128) 和 (256,144)。

抽查的二维文件使用单位 affine 和名义 1 mm spacing，不能据此判断其真实解剖方向或物理距离。需要通过上述对应关系使用原始三维 affine 恢复空间信息。

当前三维数据管线另有 (X,Y,Z)->(Z,X,Y) 转轴和降采样至 [64,128,128]，所以以上原始数组关系不能不经转换直接用于降采样 Tensor。比较时必须统一体素网格或明确共同覆盖范围。补边也需在预测后移除，再做回填。
